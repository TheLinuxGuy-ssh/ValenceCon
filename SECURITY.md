# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on the [ValenceCon Security tab](https://github.com/TheLinuxGuy-ssh/ValenceCon/security) to send a private report to the maintainers.

Include the affected version, impact, reproduction steps, and any relevant sanitized logs. Do not include API keys, passwords, private server URLs, or personal media information.

## Credential handling

ValenceCon connects to the server configured by the user and stores connection settings through Kodi's add-on settings. Treat API keys as passwords. Revoke and replace a key if it is exposed in a log, screenshot, issue, or commit.
